# JoeOS UI contract

The design system exposes semantic tokens rather than raw implementation colors: canvas, surface, line, text, muted, accent, success, warning, danger, radius, density, type scale, glass opacity, focus ring, and motion.

Widget chrome must render loading, stale, disconnected, permission-required, integration-required, denied, error, empty, and ready states. Drag and resize always have keyboard and touch-control alternatives. No status is communicated by color alone.
