# Native Codex run graph and dashboard depth

The owner's AI workspace includes a live graph of the selected conversation/run, visible messages, specialist agents, explicit workspace tools and real permission requests. Select a node to inspect recorded arguments, results, output and measured duration. Graph and metric tiles share selection; keyboard navigation, pan, zoom, fit, focus and mobile Graph/Usage/Details views are supported. Completed conversation runs can be selected; an active run remains selected for Stop and approval handling.

Pause graph freezes its drawing only. Existing execution, Stop and permission cards remain live. Countdown uses server time plus local monotonic elapsed time. A graph node cannot approve a tool: the original one-time owner token and bound request remain authoritative. No permission is generated for display. The graph contains no review tokens or authority bindings. Historical Observatory remains separate and unchanged.

Telemetry is additive in the existing owner-scoped event ledger; no schema migration. Tools correlate by a hash of run plus native call identifiers, never tool name or arrival order. Argument envelopes are limited to 16 KiB, result/error/visible-message envelopes to 32 KiB with original byte length and explicit truncation. Only visible agent messages and native-reported token counts are recorded; no hidden reasoning or account notifications. Latest native thread usage replaces repeated cumulative reports. Missing metrics are **Not recorded**, never invented zeroes. Usage coverage shows how many agents reported. Concurrent tool durations overlap and include approval wait.

Older events remain readable without invented correlations. The UI retains up to 1,200 nodes and reports the display limit; the ledger retains its events. Project/conversation changes and logout clear graph state. Rendering text as text prevents executable model/tool content.

The existing dashboard panels gain embossed edges, inset surfaces and layered shadows. Decorative orbital motion and small hover tilts add depth without rotating text or controls. Home and graph controls can restore original depth or pause motion. These preferences use separate local browser keys (`prfkt.presentation.*`); server settings remain unchanged. OS reduced motion and the existing reduced-motion setting override animation. Motion suspends when the page is hidden. No images, dependencies or background execution services are added.
