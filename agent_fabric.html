How JoeOS agents work

Each agent is a configured specialist with a defined role. They run on your local model provider inside this machine, and every run records the provider and model that was used.

  1. Ask Joe — give Joe an objective; he plans, delegates to the right specialist, verifies, and reports.
  2. Talk — send a single message to any specialist and read its reply.
  3. Start a task — give one specialist a concrete objective to execute.
  4. Team council — bring the whole team together to deliberate on a question.
  5. Activity — every run appears here with its status and the provider/model that performed it.

Runs you start are authenticated, bounded, and recorded in the Agent Fabric. Nothing runs without an active session, and no external provider is contacted.
